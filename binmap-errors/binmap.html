exception binmap.BinmapError

Bases: Exception

Base class of every exception binmap raises.

exception binmap.BinmapTypeError

Bases: BinmapError, TypeError, error

A value has the wrong type for its field, or a class definition is invalid (a field type binmap can’t pack, two last calculated fields).

Also a TypeError, and a struct.error, which binmap raised for wrong types before 2.0.

exception binmap.BinmapValueError

Bases: BinmapError, ValueError, error

A value doesn’t fit its field, binary data doesn’t match the class, or a class is defined with a bad byteorder or default.

Also a ValueError, and a struct.error, which binmap raised for these before 2.0.

class binmap.EnumField(name: str, enumclass: Type[IntEnum] | Type[IntFlag])

Bases: BinField

EnumField descriptor for fields made with enumfield(). Accepts a member, a member’s name or a number. A name stores the member it names; a number is stored as given. Either way the value must belong to the enum and fit the field, like any other field’s value.

Raises:

  • BinmapValueError – for a name or number that isn’t a member’s, or a value that doesn’t fit the field

  • BinmapTypeError – for anything but a name or an int
